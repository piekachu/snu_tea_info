# 소모임 신청 백엔드 설정 (Google Sheets + Apps Script)

`join` 페이지는 지금 **데모 모드**로 동작해요 — 브라우저(내 컴퓨터)에만 데이터가 저장돼서
다른 사람에게는 보이지 않아요. 아래 단계를 따라 실제 배포를 마치면, 만든 소모임과 신청 내역이
Google Sheet에 저장되고 누구에게나 똑같이 보이게 돼요.

이미 계정/권한 문제로 막히는 단계가 있으면(예: 조직 계정이라 배포 정책이 막혀 있는 경우) 저에게
알려주시면 대안(개인 Google 계정 사용 등)을 같이 찾아볼게요.

## 1. 새 Google Sheet 만들기

1. [sheets.google.com](https://sheets.google.com)에서 새 스프레드시트를 만들어요.
   이름은 아무거나 괜찮아요 (예: "설다연 소모임 신청").

## 2. Apps Script 붙이기

1. 시트 메뉴에서 **확장 프로그램 > Apps Script**를 눌러요.
2. 열린 편집기의 `Code.gs` 내용을 전부 지우고, 이 폴더의 [`Code.gs`](Code.gs) 내용을
   그대로 복사해서 붙여넣어요.
3. 저장 (⌘S / Ctrl+S).

## 3. 초기 설정 실행

1. 상단 함수 선택 드롭다운에서 `setup`을 선택하고 ▶ **실행**을 눌러요.
2. 처음 실행하면 "권한 검토" 창이 떠요 — 본인 계정으로 로그인하고, "고급" >
   "(프로젝트 이름)(으)로 이동" > "허용"을 눌러 승인해주세요. (Google이 안전하지 않다고
   경고하는 건 이 스크립트가 아직 Google 심사를 받지 않은 개인 스크립트라서 뜨는
   정상적인 안내예요 — 본인이 직접 만든 스크립트니 승인해도 안전해요.)
3. 실행이 끝나면 스프레드시트로 돌아가 **Events**, **Signups** 두 개의 탭이
   헤더 행과 함께 생겼는지 확인해요.

## 4. 웹 앱으로 배포

1. Apps Script 편집기 오른쪽 위 **배포 > 새 배포**를 눌러요.
2. 유형 선택(톱니바퀴)에서 **웹 앱**을 선택해요.
3. 설정:
   - **실행 계정**: 나 (Me)
   - **액세스 권한이 있는 사용자**: **모든 사용자** (Anyone) — 로그인 없이 아무나 페이지를
     쓸 수 있으려면 이 설정이 꼭 필요해요.
4. **배포**를 누르고, 다시 한번 권한 승인이 뜨면 승인해요.
5. 완료되면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec` 형태)을
   복사해요.

## 5. 관리자 비밀번호 설정 (선택이지만 추천)

이걸 설정해두면, 소모임 만든 사람이 아니어도 관리자가 아무 소모임이나(신청자가 있어도)
지울 수 있게 돼요 — 스팸이나 문제 있는 소모임을 정리할 때 씁니다.

1. Apps Script 편집기 왼쪽의 **프로젝트 설정**(톱니바퀴 아이콘) 으로 이동해요.
2. **스크립트 속성** 섹션에서 **스크립트 속성 추가**를 눌러요.
3. 속성 이름에 `ADMIN_PASSWORD`, 값에 원하는 비밀번호를 입력하고 저장해요.
   (다른 곳에서 쓰는 비밀번호를 재사용하지 마세요 — 이 값은 페이지 URL의 쿼리 파라미터로
   전송되기 때문에, 이 용도로만 쓰는 별도의 문자열을 추천해요.)
4. 설정하지 않으면 관리자 삭제 기능은 그냥 항상 비활성화 상태로 남아요 (아무도 못 씀).

이 값은 Script Properties에만 저장되고 `Code.gs` 코드에는 전혀 등장하지 않으니,
깃허브 저장소에 커밋되는 코드에는 비밀번호가 남지 않아요.

## 6. 사이트에 URL 연결

`motherPage/join/join-config.js` 파일을 열어서:

```js
window.JOIN_APPS_SCRIPT_URL = "여기에_방금_복사한_URL_붙여넣기";
```

로 채워넣고 저장, 커밋 후 푸시하면 데모 모드 배너가 사라지고 실제 Google Sheet에
저장되기 시작해요.

## 이후 코드를 수정하게 되면

`Code.gs`를 다시 수정한 뒤에는, **배포 > 배포 관리 > (연필 아이콘) > 버전: 새 버전 > 배포**를
눌러야 실제 웹 앱에 반영돼요. 그냥 저장만 하면 이미 배포된 URL은 예전 코드로 계속 동작해요.

**한 번만: `Events` 탭 재생성이 필요해요.** 이번 업데이트로 `Events` 탭에 열이 3개
추가되고 순서도 바뀌었어요 (`mapLink`, `password`, `hostSignupId`). `setup`은 헤더 행이
이미 있는 시트는 건드리지 않으므로, 기존에 만들어둔 `Events` 탭이 있다면:

1. (비어 있는 게 확인되면) `Events` 탭을 완전히 삭제해요 — 탭 이름 위에서 우클릭 > 삭제.
2. Apps Script 편집기에서 `setup`을 다시 실행해요. 새 헤더로 `Events` 탭이 다시 만들어져요.

이미 등록된 소모임이 있다면 삭제 전에 내용을 따로 적어두고, 새 탭이 만들어진 뒤 같은 값을
새 열 순서(`id | date | time | title | location | mapLink | capacity | host | description |
password | hostSignupId | createdAt | editToken`)에 맞춰 다시 입력해주세요 — `password`와
`hostSignupId`는 기존에 없던 값이라 빈 칸으로 두면, 그 소모임은 비밀번호로 관리하지 못하고
참가 인원에 주최자가 자동으로 포함되지 않아요.

## 참고: 운영/관리

- **참가자 연락처**는 신청 시 입력받지만, 공개 목록에는 이름만 보여요. 연락처는
  **주최자만** 볼 수 있어요 — 소모임 상세 화면에서 (같은 브라우저이거나 "비밀번호로 관리"로
  비밀번호를 입력한 뒤) "참가자 연락처 보기"를 누르면 이름과 연락처가 함께 나와요.
  관리자(`ADMIN_PASSWORD`)도 볼 수 있고, 시트 소유자는 언제든 `Signups` 탭에서 직접
  확인할 수 있어요.
- 소모임을 만들 때 정원에는 **본인(주최자)도 포함돼요** — 정원 1로 만들면 본인 혼자, 정원 5면
  본인 포함 5명까지예요. 만들자마자 자동으로 본인 몫 1자리가 채워진 상태로 시작해요.
- **신청 마감**: 참가 신청은 행사 시작 **24시간 전**에 자동으로 닫혀요. 그 이후에는 상세 화면에
  신청 폼 대신 "신청이 마감되었어요" 안내가 뜨고, 서버에서도 신청을 막아요. 시간을 지정하지
  않은 소모임은 그 날짜의 자정(00:00)을 기준으로 계산해요. (마감 기준 시각은 시트의
  시간대 = 한국 시간을 따라요.) 이미 신청한 사람의 취소는 마감 이후에도 가능해요.
- 소모임을 만들 때 반드시 **비밀번호**를 설정해요. 이 비밀번호로 나중에 (만든 그 브라우저가
  아니어도) 소모임을 수정하거나 삭제할 수 있어요 — 소모임 상세 화면의 "비밀번호로 관리"를
  누르면 돼요. 같은 브라우저에서는 비밀번호 없이도 바로 수정/삭제 버튼이 보여요.
- 수정은 언제든 가능하지만, 삭제는 **본인 말고 다른 참가자가 없을 때만** 가능해요 (이미 다른
  사람이 신청했으면 막아둠). 다른 참가자가 있어도 지워야 하면, 소모임 상세 화면 맨 아래
  "관리자 권한으로 삭제"를 눌러 5단계에서 설정한 `ADMIN_PASSWORD`를 입력하면 신청자 목록까지
  함께 정리하며 삭제돼요. (관리자 비밀번호를 설정하지 않았다면 이 버튼은 항상 실패해요.)
- 참고로 이 비밀번호들은 모두 평문으로 시트에 저장/전송돼요 — 동아리 운영 목적의 가벼운
  잠금장치일 뿐, 실제 계정 비밀번호 등 민감한 것을 재사용하지 않도록 안내해주세요.
- 그 외에도 급하면 시트에서 해당 행을 직접 삭제해도 돼요.
